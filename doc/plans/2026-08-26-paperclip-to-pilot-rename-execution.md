# Paperclip → Pilot Rename Implementation Plan

> **REQUIRED SUB-SKILL:** Use the executing-plans skill to implement this plan task-by-task.

**Goal:** Rename the product's code-level identity from Paperclip to Pilot across identifiers, environment variables, strings, and docs — without breaking any running deployment, sandboxed agent, or user script.

**Architecture:** Tiered rename executed bottom-up with verification gates. Tier 2 (identifiers) via ast-grep rules already in-tree; tier 3 (env vars) behind a read-time alias shim + write-time dual emission so `PAPERCLIP_*` stays honored for a release window; tier 4 (free strings/comments) via scoped ast-grep rules + reviewed fastmod; tier DB (sentinel values + plugin tables) via generated/hand-written migrations with dual-read; tier 1 (docs) last so they describe final state. Paths (`/paperclip`, `~/.paperclip*`), the `@paperclipai/*` npm scope, and `~/.pi/paperclips/` are **explicitly deferred** (see "Out of Scope").

**Tech Stack:** ast-grep 0.45.x (rules in `scripts/rename/rules/`, generated by `scripts/rename/generate-rules.mjs`), fastmod (literal replace), pnpm vitest workspace, tsc.

**Branch:** `rename/paperclip-to-pilot` (already pushed, based on `patty`).

```typescript
// packages/shared/src/env-alias.ts
const LEGACY_PREFIX = "PAPERCLIP_";
const TARGET_PREFIX = "PILOT_";

/**
 * Boot-time compat shim for the Paperclip→Pilot env rename. Copies every set
 * PAPERCLIP_X onto unset PILOT_X (never the reverse, never overwriting).
 * Call once at process entry before any config read. Returns the names mapped
 * so callers can log the alias window is active. Remove with the PAPERCLIP_*
 * deprecation in a future major.
 */
export function applyLegacyPaperclipEnvAliases(): string[] {
  const mapped: string[] = [];
  for (const key of Object.keys(process.env)) {
    if (!key.startsWith(LEGACY_PREFIX) || key === LEGACY_PREFIX) continue;
    const target = TARGET_PREFIX + key.slice(LEGACY_PREFIX.length);
    if (process.env[target] === undefined) {
      process.env[target] = process.env[key];
      mapped.push(target);
    }
  }
  return mapped;
}
```
